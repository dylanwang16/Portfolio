Machine Learning Course

Animal Image Classification Project

Role: ML Engineer / Researcher

Assignment: Designed and implemented three machine learning models (CNN, SVM, Random Forest) to classify animal images into 10 categories using a custom dataset and multiple feature extraction techniques.

  • Designed and trained a custom CNN architecture: implemented a deep learning model from scratch using Keras to perform multi-class animal classification; despite limited data, achieved solid baseline performance (67.74% accuracy) and demonstrated progressive learning across epochs.
  • Engineered and extracted handcrafted features: used image histograms, edge detection, statistical metrics, and Hu moments to create structured input for traditional models.
  • Leveraged transfer learning with MobileNetV2: extracted deep CNN features from pre-trained weights and combined them with handcrafted features.
  • Trained and evaluated SVM and Random Forest models: used PCA and feature scaling to improve generalization; SVM achieved 94.20% test accuracy and Random Forest achieved 91.24%.
  • Visualized results: generated confusion matrices, ROC curves, and precision-recall curves to analyze model performance and validate classification robustness.
